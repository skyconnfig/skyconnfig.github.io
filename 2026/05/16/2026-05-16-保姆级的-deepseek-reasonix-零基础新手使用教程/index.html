保姆级的 DeepSeek-Reasonix 零基础新手使用教程

2026-05-16 · 教程 · 更新于 2026-05-16 · 阅读
教程

给你安排一份绝对保姆级的 DeepSeek-Reasonix 零基础新手使用教程！

我们从最基础的环境准备开始，一步步带你把它跑起来，并学会怎么让它帮你自动写代码、改 Bug。

🛠️ 第一步：准备工作（必须满足的两个条件）

在开始之前，确保你的电脑里有两样东西：

1. 安装 Node.js

Reasonix 是一个基于 Node.js 开发的工具，你的电脑必须安装它。

  • 怎么检查：打开你电脑的终端（Windows 按 Win + R 输入 cmd；Mac 打开 Terminal），输入以下命令并回车：
  • 如果有输出类似 v20.x.x 或 v22.x.x 的版本号，说明已经装好了。
  • 如果提示“找不到命令”，请去 Node.js 官网 (nodejs.org) 下载长期支持版（LTS），一路点击“下一步”安装，安装完记得重启终端。

2. 准备好 DeepSeek API Key

  • 如果你之前在 OmniRoute 里已经绑定了 SiliconFlow（硅基流动）或者 DeepSeek 官方的 Key，直接拿来用就可以。

🚀 第二步：进入你的代码项目并启动

Reasonix 不需要全局安装，每次你想用它来改某个项目的代码时，直接在项目目录下运行即可。

  1. 在电脑上找到你正在写的代码项目文件夹。
  2. 在该文件夹的空白处右键 $\rightarrow$ 选择 “在终端中打开”（Windows 11）或使用 cd 命令切换到该目录。
  3. 在终端中直接输入以下命令并回车（这会自动拉取最新版并运行）：

🔑 第三步：首次启动的交互式配置

第一次运行 npx reasonix code 时，终端会变成一个彩色的引导界面，别慌，跟着提示做：

  1. 输入 API Key：
  • 终端会提示：Enter your DeepSeek API Key:
  • 把你复制好的 Key 粘贴进去（注意：在终端里粘贴可能不会显示任何字符，这是安全保护，直接按回车即可）。
  1. 选择提供商/服务商（Provider）：
  • 如果你用的是官方 Key，选 DeepSeek Official。
  • 如果你用的是中转或者硅基流动，选 Custom / OpenAI Compatible，然后输入对应的 Base URL。
  1. 选择默认模型预设（Preset）：
  • fast (推荐) —— 默认调用 DeepSeek-V3。速度极快，用来应付日常写写普通函数、改改小语法错、查查数据非常省钱。
  • smart —— 默认调用 DeepSeek-R1 (深度思考版)。适合高难度的架构设计、复杂的 Bug 调试、写算法，它会展现出强大的思维链。
  1. 选择交互模式：
  • 默认直接按回车，进入 Agent（带审批模式）即可。

💡 小贴士： 配置完成后，这些信息会自动安全地保存在你电脑的 ~/.reasonix/config.json 里，下次再运行就直接进去了，不需要重复配置！

🧑‍💻 第四步：实战演练（怎么让它写代码）

配置好后，你会看到终端里出现了一个对话框。这也就是你的“AI 编程副驾驶”了。

场景一：让它帮你写一个新功能

你可以直接用中文下达指令：

  • 接下来会发生什么：
    Reasonix 会自己去创建文件，写好代码。因为它是 Agent 模式，在修改你本地磁盘前，终端会弹出一个精美的 Diff（代码前后对比） 面板，并询问你：
    Do you want to apply these changes? (y/N)（你是否同意修改？）
  • 你的操作：输入 y 然后回车，代码就真正写入你的文件了！

场景二：让它帮你找出代码里的 Bug 并修复

  • 接下来会发生什么：
  1. Reasonix 会通过内置工具去读取你的 auth.js 文件。
  2. 它会尝试在它的“安全沙盒”里运行类似 npm run test 或相关的启动命令。
  3. 如果报错了，它能自动拦截报错信息，利用它的 Tool-Call Repair (工具修复机制) 自动写出修复方案。
  4. 再次向你展示修改对比，你输入 y 确认，Bug 搞定！

🛠️ 第五步：常用快捷键与命令

在 Reasonix 的对话终端里，有一些非常好用的独家指令，你可以直接在聊天框里敲：

  • /model：随时切换模型。比如写普通代码用 V3（省钱），突然遇到卡壳的难题了，敲 /model smart 切换到 R1 满血版帮你通宵攻坚。
  • /status：查看当前帮你省了多少钱。它会列出本次会话中 Prefix Caching（前缀缓存） 的命中率。你会发现长对话里大段大段的上下文都在吃一折优惠，越用越爽！
  • **exit 或 Ctrl + C**：随时退出 Reasonix 终端。

现在，去打开你的代码文件夹，敲下 npx reasonix code 开启你的第一个 AI 自动化编程体验吧！如果在配置过程中有任何报错，随时截个图发给我。

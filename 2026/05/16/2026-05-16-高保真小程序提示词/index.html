高保真小程序提示词

2026-05-16 · 开发 · 更新于 2026-05-16 · 阅读
开发

角色与核心任务

你是一名精通前端开发（HTML5 / Tailwind CSS / JavaScript）的资深 UI/UX 设计师。请根据以下严格的设计规范，为一个名为“【请在此处替换你的小程序名称，例如：绿动健康/OmniRoute管理端】”的小程序，独立设计并输出一个单文件、高保真、可交互的 H5 前端原型页面。

📐 尺寸与容器规范（设备模拟）

  1. 严格的物理边界：必须使用一个居中的 div 容器来模拟手机视口。
  2. 绝对尺寸：该容器的宽度必须固定为 430px，高度必须固定为 932px（标准的 iPhone 14/15 Pro Max 逻辑分辨率）。
  3. 外框效果：为该容器添加圆角（rounded-[40px]）、精致的边框（border-[12px] border-slate-800）、阴影（shadow-2xl），并在顶部中央模拟一个苹果手机的“灵动岛”或刘海微型黑块，以达到极高还原度的手机壳模拟效果。
  4. 内部滚动：容器整体设置 overflow-hidden，但主体内容区域若超出高度，必须在容器内部支持平滑滚动（overflow-y-auto），绝对不能撑开或破坏外层的 430x932 框架。

🎨 视觉与色彩规范（绿色主题）

  1. 主色调：严格采用绿色系（Green Theme）。
    • 主色/品牌色：emerald-600 或 green-600
    • 渐变搭配：允许使用 from-emerald-500 to-teal-600 等富含科技感、健康感或现代感的绿色渐变。
  2. 辅助色：
    • 背景色：极浅的灰绿底色（如 bg-slate-50 或 bg-stone-50），用以衬托卡片。
    • 文字色：深色字用 text-slate-800，副文本用 text-slate-400。
  3. 组件一致性：所有按钮、激活态的 Tab、图标、标签、进度条等视觉元素，必须统一使用上述绿色系，严禁出现蓝、红（除警告动作外）等突兀冲突的颜色。

🧱 布局与组件规范（卡片式高保真）

  1. 头部与尾部（Fixed Elements）：
    • 顶部状态栏/导航栏：模拟手机状态栏（时间、信号、电池图标），下方为标准的微信小程序式导航栏（左侧返回/主页，中间标题，右侧胶囊按钮 ... ⋮ ⭕）。
    • 底部 TabBar 导航：固定在模拟器底部。包含 3~4 个常用菜单（如：首页、工作台、我的），使用 Font-Awesome 图标加文字，需体现出当前激活状态的绿色高亮。
  2. 主体内容区（卡片式布局）：
    • 所有列表、数据、功能模块必须采用卡片式布局（Card Layout）。
    • 卡片设计要求：纯白背景（bg-white）、精致圆角（rounded-2xl）、微弱阴影（shadow-sm 或 border border-slate-100）、合理的内边距（p-4）。
    • 卡片内需包含微交互元素（例如：轻微的悬停变色、优雅的徽章标签 badge）。

⚡ 交互与 JS 动作规范（单页面切换）

  1. 单文件架构：所有子页面（如：首页、详情页、个人中心）必须以隐藏/显示（利用 Tailwind 的 hidden 类名或 JS 控制 display）的形式存在于这同一个 HTML 文件中。
  2. 点击导航交互：编写原生 JavaScript 脚本。当用户点击底部的 TabBar 按钮、或点击卡片列表时，能够流畅地隐藏当前页面，并显示对应的子页面或详情页，实现完备的业务流转闭环。
  3. 状态联动：切换页面时，底部 TabBar 的图标和文字颜色必须动态同步切换（未激活态为灰色，激活态变为主题绿色）。

🛠 技术栈要求

  • HTML5：语义化标签。
  • Tailwind CSS：完全使用 Tailwind CSS 类名进行响应式和精细化样式设计，禁止编写冗长的原生 CSS（可通过 CDN 引入：<script src="https://cdn.tailwindcss.com"></script>）。
  • Font-Awesome 图标：所有图标使用 Font-Awesome v6+ 规范（可通过 CDN 引入：<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.4.0/css/all.min.css">）。
  • 原生 JavaScript：用于处理简单的 DOM 切换交互，无需引入复杂的框架。

📥 输出要求

请直接输出一段完整、没有缺失、没有注释省略的 index.html 源代码。代码必须包含完整的样式、布局和 JS 逻辑，复制到浏览器中即可直接预览并作为 H5 原型交付。

最初版提示词

你是一名专业的ui设计师，现在需要你结合文档设计要求，使用边框模拟手机边框、严格以430x932作为手机页面高度和宽度，你可以使用tailwind+html+font-awesome图标，进行设计，设计完整的原型页面，使用js加上动作交互点击能到对应子页面位置，要求整体颜色为绿色主题，可以使用绿色渐变色，按钮这些颜色也必须与主题颜色保持一致，列表展示以卡片式布局进行展示页面一定要精细、高保真、高还原。能够直接进行前端H5页面开发的原型设计做一个相亲小程序原型

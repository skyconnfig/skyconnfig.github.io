4. 常见 DNS 报错

错误 原因 解决方法
An A, AAAA, or CNAME record with that host already exists 同名记录冲突 删除原有 @ / root 的 CNAME 或 A / AAAA，保留最终方案
InvalidDNSError 子域名未配置或 DNS 不正确 添加 CNAME www → yourusername.github.io
“未找到 Ads.txt” ads.txt 文件不存在或无法访问 按上节部署 ads.txt，并灰云

  6. 检查：

    • https://lxs.best 可访问

    • GitHub Pages 设置显示 Custom domain 正确

6. Tips

  • Hexo _config.yml 的 url 和 source/CNAME 文件必须统一为自定义域名
  • 每次部署前 hexo clean 可以避免旧文件缓存导致 CNAME 覆盖
  • Cloudflare 主域名灰云（DNS Only），子域名橙云（加速可用）
  • AdSense 审核通过前，网站必须有首页和至少 5 篇文章

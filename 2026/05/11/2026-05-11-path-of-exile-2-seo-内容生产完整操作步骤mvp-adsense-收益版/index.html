Path of Exile 2 SEO 内容生产完整操作步骤（MVP → Adsense 收益版）

这是一个从 0 到可上线游戏攻略站，并能批量生产 SEO 内容的完整流程。

目标：

  • 7 天上线
  • Google 收录
  • 申请 Adsense
  • 批量生成攻略文章
  • 提高广告收益

一、网站准备阶段（必须完成）

1. 域名选择

推荐使用：

  • 主站：lxs.best
  • 子站：poe2.lxs.best（推荐）

原因：

  • 更专业
  • SEO 更清晰
  • 更容易做游戏矩阵

2. 技术栈搭建

使用：

  • Astro（静态站）
  • TailwindCSS
  • Markdown 内容
  • Vercel 部署

禁止：

  • 后端
  • 数据库
  • 登录系统
  • SSR

3. 网站基础页面

必须有：

  • 首页 /
  • /builds/
  • /guides/
  • /about
  • /privacy-policy

二、内容结构设计（SEO 核心）

1. 文章类型规划（固定）

必须只做：

  • Build Guide（构筑）
  • Farming Guide（刷资源）
  • Beginner Guide（新手）
  • Fast XP Guide（升级）
  • Tier List（强度排行）

2. URL 结构（SEO 关键）

标准格式：

  • /builds/xxx-build
  • /guides/xxx-guide

例如：

  • /builds/best-witch-build
  • /guides/how-to-farm-gold

三、AI 生成内容流程（核心）

Step 1：准备 Prompt 模板

使用统一 Prompt（你已有模板）：

  • 输入标题
  • 输入类型
  • 输入关键词

Step 2：生成文章（AI 输出）

AI 输出必须：

  • Markdown 格式
  • 英文
  • SEO 优化
  • 1500–2500词
  • 有 FAQ
  • 有结构

Step 3：人工快速检查（重要）

检查：

  • 标题是否自然
  • 是否有重复句
  • FAQ 是否合理
  • 是否有 SEO 关键词
  • 是否像“真实玩家写的”

Step 4：发布到 Astro

放入：

系统自动生成页面

四、文章模板结构（必须统一）

每篇文章必须包含：

1. Frontmatter

2. 内容结构

必须包含：

Introduction

介绍 + 关键词

Why This Build Is Strong

优势分析

Skill Setup

技能/机制

Best Gear

装备推荐

Passive Tree Tips

加点策略

Gameplay Tips

实战技巧

Pros and Cons

优缺点表格

FAQ

5–8 个 SEO 问题

Related Guides

内部链接

五、批量生成流程（赚钱核心）

Step 1：准备 20 个标题

例如：

  • Best Witch Build
  • Fast XP Guide
  • How To Farm Gold

Step 2：批量喂 AI

一次生成：

  • 5~10 篇

Step 3：快速发布

流程：

AI → Markdown → Astro → Vercel

Step 4：Google 收录

提交：

  • sitemap.xml
  • Search Console

六、Adsense 接入流程

Step 1：网站内容准备

必须：

  • 15~30 篇文章
  • About 页面
  • Privacy 页面

Step 2：申请 Adsense

提交：

  • poe2.lxs.best

Step 3：通过后加广告

布局：

  • Header 广告
  • 文中广告
  • 侧边栏广告

七、广告优化原则（重要）

必须遵守：

  • 不影响阅读
  • 不超过 3–5 个广告
  • 移动端优化
  • 正文中间插入

最佳位置：

  • 第一段后
  • FAQ 前
  • 侧边栏

八、SEO 优化关键点

必须：

  • 长尾关键词
  • FAQ Schema
  • Article Schema
  • 内链结构
  • Sitemap
  • Meta Description
  • OG Tags

九、内容增长策略（核心）

第一阶段（启动）

  • 20 篇文章

第二阶段（增长）

  • 每天 5–10 篇

第三阶段（规模）

  • 200+ 页面

十、最终目标

网站进入：

  • Google 自然流量
  • Adsense 收益
  • 长尾关键词排名
  • 自动化内容生产

十一、核心总结

整个系统本质是：

不是做网站，而是做“内容机器”。

十二、你下一步应该做什么

  1. 用这个流程生成 20 篇文章
  2. 放入 Astro
  3. 部署 Vercel
  4. 提交 Google
  5. 申请 Adsense

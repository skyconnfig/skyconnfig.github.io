cc-connect 安装以及配置微信

2026-05-14 · 部署 · 更新于 2026-05-14
部署

一、先安装基础环境

  1. 安装 Node.js（必须）

打开：

Node.js 官网

下载：

LTS 版本
Windows x64 Installer (.msi)

安装时：

一路 Next
勾选：
Add to PATH

安装完成后：

打开 PowerShell：

node -v
npm -v

如果能看到版本号说明成功。

例如：

v22.x.x
10.x.x
二、安装 cc-connect

官方支持 npm 全局安装。

PowerShell 执行：

npm install -g cc-connect

安装完成后检查：

cc-connect –version

如果连接微信不了是不是初始化
cc-connect init

微信初始化
cc-connect weixin setup

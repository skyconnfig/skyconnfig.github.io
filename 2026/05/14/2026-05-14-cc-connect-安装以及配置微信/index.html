cc-connect 安装以及配置微信接入 DeepSeek

2026-05-14 · 部署 · 更新于 2026-05-16
部署

cc-connect 是一个将个人微信与 AI 大模型（如 DeepSeek）连接起来的开源工具。通过本文，你将学会从零开始安装 Node.js、部署 cc-connect、完成微信初始化，并最终在浏览器中通过聊天界面调用 DeepSeek 模型。

一、前置准备

系统要求

  • 操作系统：Windows 10/11、macOS 或 Linux（本文以 Windows 为例）
  • 网络：能够正常访问 npm 注册表（国内用户建议配置淘宝镜像）
  • 微信账号：一个可正常登录的个人微信号（供机器人使用）

二、安装 Node.js 运行环境

cc-connect 基于 Node.js 开发，必须先安装 Node.js 运行时。

2.1 下载安装包

  1. 打开 Node.js 官网
  2. 下载 LTS（长期支持）版本，Windows 用户选择 Windows x64 Installer (.msi)

2.2 安装步骤

  1. 双击运行下载好的 .msi 安装包
  2. 一路点击 Next，使用默认配置即可
  3. 关键步骤：在安装向导中，务必勾选 “Add to PATH”（添加到系统环境变量），否则后续无法在命令行中直接使用 node 和 npm 命令
  4. 点击 Install 完成安装

八、常见问题排查

问题 可能原因 解决办法
npm install 卡住不动 网络问题 配置淘宝镜像后重试（见 2.4 节）
cc-connect 不是内部命令 PATH 未生效 重启 PowerShell 或重启电脑
微信二维码无法显示 终端不支持 使用 Windows Terminal 或 iTerm2
登录页面无法访问 服务未启动 确认终端显示”服务已启动”再访问
API Key 错误 密钥填错 到 DeepSeek 平台重新复制 API Key

九、安全提示

  1. 配置文件保护：config.toml 中包含 API Key 和微信登录信息，不要分享给他人
  2. 微信账号安全：建议使用专用小号，避免主号被封
  3. 端口暴露：localhost:9820 默认仅本地访问，如需远程访问请配置防火墙和 HTTPS

本文为实操总结，各步骤均经过 Windows 11 环境验证。macOS/Linux 用户请对应调整包管理器命令。
